**Meeno** is an ultra-lightweight (<30 KB), zero-dependency security firewall and guidance layer built for the **Open Agentic Web Challenge**. It protects AI web agents from hidden indirect prompt injections across all world languages before any sensitive action is executed.

## ✨ Key Features
* **Cross-Lingual Threat Detection:** Scans untrusted DOM contexts and tool payloads across 12+ major global scripts (English, Arabic, French, Spanish, German, Portuguese, Russian, Chinese, Japanese, Korean, Hindi, and Turkish).
* **Cryptographic Trust Passes:** Generates instant `SHA-256` capability hashes via the native **Web Crypto API** for verified, clean actions.
* **Standardized Agent Discovery:** Exposes `agent.network.json` and `agent-mcp.json` manifests alongside native `navigator.modelContext` (`WebMCP`) tool registration (`verify_agent_action`).
* **Installable Mobile & Desktop App (PWA):** Includes `manifest.json` and a Service Worker (`sw.js`) for instant offline caching and home-screen installation.
* **Zero-KB Calm Ambient Audio:** Built-in procedural Web Audio API synthesizer offering optional soothing background audio.
